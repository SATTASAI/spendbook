รหัสแอป (ใช้ใส่ในคำสั่งลัด)
ตั้งคำสั่งลัด: บันทึกจาก SMS ธนาคารอัตโนมัติ
  1. เปิดแอป คำสั่งลัด → แท็บ ระบบอัตโนมัติ → แตะ + → เลือก ข้อความ
  2. ผู้ส่ง: เลือกชื่อผู้ส่ง SMS ของธนาคาร (เช่น KBank, SCB) เลือก เรียกใช้ทันที แล้วแตะ ถัดไป → ระบบอัตโนมัติเปล่า
  3. เพิ่มการทำงาน รับเนื้อหาของ URL ใส่ URL ด้านบน แตะ ▸ เพื่อขยาย:
    • วิธีการ: POST
    • ส่วนหัว: เพิ่ม Authorization = รหัสแอปด้านบน
    • เนื้อหาคำขอ: JSON เพิ่มช่อง text = อินพุตคำสั่งลัด (เลือก เนื้อหา), source = sms, sender = อินพุตคำสั่งลัด (เลือก ผู้ส่ง)
  4. เพิ่ม รับค่าพจนานุกรม คีย์ message แล้วเพิ่ม แสดงการแจ้งเตือน ให้แสดงค่านั้น
  5. ทำซ้ำข้อ 1–4 สำหรับธนาคารอื่นที่ใช้

ไม่บันทึก SMS เงินเข้าและรหัส OTP · ถ้า SMS กับสลิปเป็นรายการเดียวกัน ระบบจะรวมให้ ไม่นับซ้ำ

ตั้งคำสั่งลัด: แชร์สลิปเข้าแอป
  1. แอป คำสั่งลัด → แท็บ คำสั่งลัด → + ตั้งชื่อ บันทึกสลิป
  2. แตะ ⓘ → เปิด แสดงในแผ่นงานแชร์ ให้รับเฉพาะ รูปภาพ
  3. เพิ่ม ดึงข้อความออกจากรูปภาพ (รูปภาพ = อินพุตคำสั่งลัด)
  4. เพิ่ม รับเนื้อหาของ URL ตั้งค่าเหมือนข้างบน แต่ text = ข้อความ และ source = slip
  5. เพิ่ม รับค่าพจนานุกรม คีย์ message → แสดงการแจ้งเตือน

ใช้: โอนเงินเสร็จ → แชร์สลิป (หรือแชร์จากแอปรูปภาพ) → เลือก “บันทึกสลิป” ถ้าระบบอ่านไม่ครบ รายการจะขึ้นป้าย “รอตรวจ” ให้แก้ในแอป
